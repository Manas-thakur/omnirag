On-call Runbook

This runbook covers the most common alerts for the Notes platform.

High p95 latency

If the p95 latency of the Notes API stays above 250 ms for ten minutes, check the Redis cache hit rate first. A cold or evicted cache sends every read to PostgreSQL. Scaling the API replicas rarely helps when the database is the bottleneck.

Spike in HTTP 429 responses

A sudden increase in 429 responses usually means a single client exceeded its rate limit. Look up the API key in the gateway logs before raising any limits.

Database failover

  • Promote the eu-west read replica only after confirming the primary is down.
  • Update the DATABASE_URL secret and restart the API pods.
  • Announce the incident in the #notes-incidents channel.
